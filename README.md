# Проект автоматизации тестирования веб-приложения Яндекс Самокат

1. В проекте UI-тесты для веб-приложения Яндекс Самокат.
2. Для их написания использовались Python, фреймворк pytest, Selenium, JDK(Java Development Kit), фреймворк Allure и библиотека allure-pytest.
3. Установить необходимые зависимости по отдельности или все одной командой:
    - pip install pytest
    - pip install selenium
    - pip install allure-pytest
    - pip3 install -r requirements.txt
4. Команда для запуска всех тестов:
    python -m pytest -s
